# IT1214-Student-Grade-System

## Project Purpose
The Student Grade Management System is a lightweight, Java console application built to digitize paper-based and spreadsheet academic tracking methods. It encapsulates structural student models leveraging proper Object-Oriented Programming (OOP) properties and allows educators to manage rosters, seek student records efficiently via unique keys, and monitor institutional class averages.

## How to Run the Program

### System Requirements
* Java Development Kit (JDK) 8 or higher installed.

### Compilation & Execution Steps
1. Open your native command-line interface or VS Code Terminal.
2. Compile both Java source files simultaneously:
   ```bash
   javac Main.java
